# FitFuel - Healthy Meal Planner

## Project Description

FitFuel is a responsive single-page web application designed to help users explore healthy meal plans based on their fitness goals.

The website provides meal plans for weight loss, muscle gain, and balanced nutrition along with useful information about healthy eating.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features

- Responsive navigation bar
- Hero/banner section
- Healthy lifestyle information
- Meal plan cards
- Weight Loss meal plan
- Muscle Gain meal plan
- Balanced Diet meal plan
- Bootstrap Modal
- FAQ Accordion
- Contact section
- Responsive footer
- Responsive design for desktop, tablet and mobile

## Bootstrap Components Used

The following Bootstrap components/features are used:

1. Navbar
2. Responsive Grid System
3. Cards
4. Buttons
5. Modal
6. Accordion
7. Form Controls
8. Responsive Utilities
